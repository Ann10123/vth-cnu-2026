# Робота на ноутбуках із 8 ГБ RAM (Windows 10 / WSL2)

> УВАГА: Кроки нижче лише рекомендовані, але не є обов'язковими для виконання! Актуальні лише для слабких машин.

Мікросервіси проєкту вже налаштовані на низьке споживання пам'яті (`-Xms64m -Xmx128m -XX:+UseSerialGC` для локального запуску та `-Xmx512m` для Gradle Daemon). Щоб система стабільно працювала на машинах класу Windows 10 із 8 ГБ оперативної пам'яті:

## 1. Обмеження пам'яті WSL2 (`.wslconfig`)
За замовчуванням WSL2 резервує до 50% RAM для Docker. Створіть або оновіть файл `C:\Users\<Ваш_Користувач>\.wslconfig`:

```ini
[wsl2]
memory=2GB
processors=2
swap=2GB
```

Після збереження перезапустіть WSL у PowerShell:
```powershell
wsl --shutdown
```

## 2. Почерговий запуск або хмарна БД (Neon)
- **Тестування окремого модуля (найшвидше):** під час виконання лабораторних запускайте тести лише потрібного сервісу:
  ```bash
  ./gradlew :match-analytics-service:test
  ./gradlew :rank-calculator-service:test
  ```
- **Розробка без локального Docker:** створіть безкоштовну базу даних у **Neon PostgreSQL**, вкажіть її URL у змінних оточення (`DB_URL`, `DB_USER`, `DB_PASSWORD`) — тоді Docker Desktop можна не запускати під час роботи над сервісом.
- **Робота лише з фронтендом:** використовуйте автономний режим `make dev-mock` (~150 МБ RAM).
